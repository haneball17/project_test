## 📞 快速帮助

### 常见问题

**Q: 我应该先读哪个文档？**
A: 建议从 [开发职责分工表](./02-开发指南/开发职责分工表.md) 开始，然后阅读 [项目开发手册-C#版](./02-开发指南/项目开发手册-C#版.md)

**Q: Godot-MCP 必须安装吗？**
A: 不是必须的。它是一个可选的增强工具，可以大幅提升效率。详见 [Godot-MCP 具体用途](./03-技术方案/Godot-MCP具体用途.md)

**Q: 我应该用 GDScript 还是 C#？**
A: 您已经下载了 Godot C# 版本，建议继续使用 C#。所有文档和代码示例都基于 C#。

**Q: 需要安装额外工具吗？**
A: 基础开发只需要 Godot .NET 版本和 .NET SDK。Godot-MCP 和其他工具都是可选的。
