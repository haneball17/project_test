# project_test 游戏开发手册（总览）

## 1. 文档定位
本手册用于说明项目目标、范围和边界，不承载具体实现细节。

实现细节请查看：[`项目开发手册-C#版.md`](./项目开发手册-C#版.md)

## 2. 项目目的
本项目用于构建一个 **Godot 4.x + C#** 的 **2.5D ARPG Demo**，验证以下核心能力：
- 角色在 3D 空间中的 2.5D 移动体验
- 俯视/斜视相机跟随
- 敌人基础 AI（巡逻/追击）
- 攻击命中与受击反馈
- 最小可用 UI（血量、提示）

## 3. 非目标（当前阶段不做）
- 完整剧情系统
- 大规模关卡编辑器工具链
- 多平台全量发布（尤其 Web 平台 C# 导出）
- 复杂联网与多人同步

## 4. 当前仓库现状（截至 2026-02-28）
- 已初始化 Godot 工程（`project.godot`）。
- 已存在 `.NET` 相关配置节。
- 尚无 `scenes/`、`scripts/`、`assets/` 等业务目录内容。
- 当前主要交付是文档与开发规划，不是可玩版本。
- 当前本地开发版本：`Godot Engine v4.6.1`。

## 5. 推荐开发边界
建议按最小闭环推进：
1. 玩家可移动
2. 相机可跟随
3. 至少一个敌人可被攻击并反馈
4. UI 可显示关键状态

达到上述闭环后再扩展：状态机、技能系统、存档系统。
